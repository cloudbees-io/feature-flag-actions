= Add Target Group

link:../README.adoc[← Index]

Add a Target Group configuration to a Feature Flag in a specific environment.

== Inputs

[cols="2a,2a,2a,5a",options="header"]
.Input details
|===

| Input name
| Data type
| Required?
| Description

| `api_token`
| String
| No
| The Unify API token used to make the configuration change. If not defined, the action will use a secret named `FEATURE_FLAG_ACTIONS_API_TOKEN` or will error.

| `app_id`
| String
| Yes
| The Unify application ID with which the Feature Flag is associated.

| `flag_id`
| String
| Yes
| The Feature Flag UUID.

| `env_id`
| String
| Yes
| The Unify environment ID in which the Target Group is to be added.

|===

See link:https://github.com/cloudbees-io/feature-flag-actions/tree/main#common-action-inputs[Common Action Inputs] for more details on the above inputs.
