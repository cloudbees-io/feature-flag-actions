= Add Target Group

link:../README.adoc[← Index]

Add a Target Group as a condition on a Feature Flag in a specific environment.

The action looks up the Target Group by name, constructs the appropriate condition object, and patches the flag's condition list. New conditions are prepended so they take precedence over existing ones. See link:../internal/patch-flag/README.adoc[patch-flag] for full details on how condition merging works.

== Inputs

[cols="2a,2a,2a,5a",options="header"]
.Input details
|===

| Input name
| Data type
| Required?
| Description

| `api_token`
| String
| No
| The Unify API token used to make the configuration change. If not defined, the action will use a secret named `FEATURE_FLAG_ACTIONS_API_TOKEN` or will error.

| `app_id`
| String
| Yes
| The Unify application ID with which the Feature Flag is associated.

| `flag_id`
| String
| Yes
| The Feature Flag UUID.

| `env_id`
| String
| Yes
| The Unify environment ID in which the Target Group condition is to be added.

| `target_group_name`
| String
| Yes
| The name of the Target Group to add as a condition.

| `matches`
| Boolean
| Yes
| Whether the flag value is returned when the user matches the Target Group (`true`) or does not match it (`false`).

| `flag_value`
| Any
| Yes
| The flag value to return when the condition matches e.g. `true`, `false`, or a string variant value.

|===

See link:https://github.com/cloudbees-io/feature-flag-actions/tree/main#common-action-inputs[Common Action Inputs] for more details on the `api_token`, `app_id`, `flag_id`, and `env_id` inputs.

== Usage

The example below assumes the API token has been stored as a shared secret named `FEATURE_FLAG_ACTIONS_API_TOKEN`, so the `api_token` input is omitted.

[source,yaml]
----
jobs:
  build:
    steps:

      - id: add-acme-eng-target-group
        name: Add AcmeEng target group to feature flag
        uses: cloudbees-io/feature-flag-actions/add-target-group@v1
        with:
          app_id: "f5e23d42-5c3c-467d-91d7-b07158822589"
          flag_id: "a5f246e5-7c7f-4c2a-9fe0-e05538b3d640"
          env_id: "5be99972-9f87-4093-8189-c0c0a31dc571"
          target_group_name: "AcmeEng"
          matches: true
          flag_value: true
----
