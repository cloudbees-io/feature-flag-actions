= Get Resource

`GET` a Unify API resource.

NOTE: This is a low-level action intended to be called by other actions in this repo.

== Inputs

[cols="2a,2a,2a,5a",options="header"]
.Input details
|===

| Input name
| Data type
| Required?
| Description

| `api_token`
| String
| No
| The Unify API token. If not defined, the action will use a secret named `FEATURE_FLAG_ACTIONS_API_TOKEN` or will error.

| `path`
| String
| Yes
| The API path to GET (relative to `https://api.cloudbees.io/`) e.g. `v1/applications/{app_id}/flags/{flag_id}/configuration/environments/{env_id}`.

|===

== Outputs

[cols="2a,9a",options="header"]
.Output details
|===

| Output name
| Description

| `json`
| The response JSON if the request was successful. The action will fail if the request fails.

|===
